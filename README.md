Basic website for Group Trip Planner. 

Instructions for video demo:
1. (Day Overview) → Click the "Afternoon" slot card (with orange "Voting" badge) → Goes to Add Candidates
2. (Add Candidates) → Click "Start comparisons (12 pairs)" → Goes to Comparison screen
3. (Comparison) → Click either "Choose this" button or "skip / no preference" → Advances through pairs (1-12), then automatically → Goes to Results
4. (Results) → Click "Propose for lock" button → Opens/closes the lock modal
